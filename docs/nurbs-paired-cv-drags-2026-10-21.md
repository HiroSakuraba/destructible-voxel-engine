# Linked NURBS control gizmos and paired background display

Linked reference controls and free moving controls now use the same translate, rotate and scale gizmos as independent NURBS sources. A selection containing any driven moving boundary control, or the adjacent tangent row for C1, refuses the entire drag with an explanation. Both linked objects must be visible, unlocked, owned and available in the current isolation. Object-level transforms still require unlinking.

The existing single-worker tessellation queue accepts immutable two-patch snapshots for both fixed and adaptive display. Every input request derives from the exact pre-drag pair. New requests cancel the running generation and replace the pending generation. The worker checks the baseline caches, maintains C0/C1, regenerates the common seam schedule and prepares both complete displays. Stop tokens reach attachment preparation, adaptive refinement, explicit grid tessellation, continuity checking and seam-cache validation. No worker holds live document or controller pointers.

The editor retains the last complete pair while computing. Publication validates both endpoints, stages resource-preserving source/metadata/mesh replacements and then installs both on the editor thread. Source, seam metadata, geometry, placement, lock, visibility, prefab ownership, selection, isolation and document revision checks prevent stale results from being published. Material/texture resource changes are retained. A changed source/cache is preserved rather than overwritten by cancellation; if external code invalidates one side of a published preview, the external state requires explicit repair before subsequent linked editing.

Mouse release or Enter waits through editor updates for the newest request. A successful release records one prepared command covering both patches, with cached undo/redo and selection history. Preview publication does not mark a new document revision. Identity drags create no history and preserve the exact initial source/cache pair. Escape, focus loss and Undo during a drag restore both previews; Undo cancels only the active drag, keeping earlier history. Autosave skips active NURBS drags and conflicting editor commands are blocked. Direct document save/reopen after completion retains the seam relationship without serializing job state.

The inherited scope is one seam per patch, a common parent/pose/axis scale and no socket attachments. Multiple seams/junctions, graph-aware parameter refinement, network transforms, copy/prefab ID remapping, trimmed surfaces and topological sewing remain future work. Numeric and display-policy edits remain synchronous paired commands. Approximation uses the existing local-space fixed/adaptive policy; there is no camera LOD, independent viewport/render policy or certified error bound.

## Validation

All 19 selected CTest suites passed (the modeling executable needed its execute permission restored before its successful run). Dedicated coverage includes all 64 boundary/direction/C0-C1 combinations with mixed display policies, native translate/rotate/scale, free/driven controls, newest-generation release, cancellation before and after publication, focus loss, paired history and selection, material preservation, stale partner source/cache/frame, lock/deletion, queue reuse/shutdown and save/reopen. These are headless checks; windowed/GPU performance and artist acceptance remain outstanding.

A focused AddressSanitizer run also passed with the paired test and seam, queue, native NURBS transform and attachment sources instrumented. The remaining engine archives were not instrumented, and leak detection was disabled.
