# Wind Garden — Flying Transformation Starter

Generate with `dve_create_flying <NEW_PROJECT_DIRECTORY>`, or create through the editor Gameplay Prototype Kit panel.

Six forms share one continuous aircraft: floating, glider, biplane, jet, powered hover and bird soaring. Pass six ordered rings in the matching modes while preserving speed and altitude across transformations.

Controls: W/S pitch, A/D roll, Q/E yaw, Shift/Ctrl throttle, arrow Up/Down climb in hover, Tab/Backspace cycle modes, keys 1–6 direct requests, Space flap as bird, B airbrake, C switch camera, X recover, P pause, R restart, F3 diagnostics. Gamepad sticks, shoulders, triggers and face buttons also work.

The level has colored gates, low-poly terrain and a simple rising-air pocket near X=50, Y=280. This is the F1 physics/controller baseline; flight morph animation, elaborate weather, and audio are later phases.
